***********************************************RUTA SSL CONFIGURATION POSTILION*****************************************************

Configuring a specific console to use a different connection string

It is possible to configure a specific console to use a a different connection string when connecting to the database. The connection string can be manually configured under the HKEY_LOCAL_MACHINE\SOFTWARE\Mosaic Software\Postilion\Consoles\<console name>\Database key (or under HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\Mosaic Software\Postilion\Consoles\<console name>\Database when using a 64-bit registry editor) in a REG_SZ value with the name ConnectionString.SQL Server. Similarly, the connection string used when connecting to an IBM DB2LUW database is stored under the same key in a REG_SZ value with the name ConnectionString.DB2LUW. The connection string can contain the same tokens as the recommended connection string.
